# Auditoria de segurança e performance — 2026-11-25

Ponto de partida do hardening do repositório. Cada achado aponta o PR que o trata.

## Varredura retroativa de segredos

- Ferramenta: gitleaks (regras padrão + `.gitleaks.toml`), sobre `git log --all`.
- Resultado: **16 commits, nenhum vazamento**. Nenhum `.env`, chave privada ou JSON de service account foi versionado em qualquer branch.
- Conclusão: **não é preciso reescrever o histórico** nem rotacionar credenciais por vazamento no git.
- GitHub: secret scanning e push protection já estavam ativos.
